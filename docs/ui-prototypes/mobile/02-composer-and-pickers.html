Where the picks can live — the four honest options

Option What you see at rest Taps to change the model Cost
A · Header chips provider · model · mode · effort · meter under the title 1 ~40px of every session page, always
B · Composer picks a quiet row under the text field; the header is only the title 1 composer is two rows (~84px) instead of one (~52px)
C · One summary chip provider icon + model inside the field; nothing else 2 (pull up, then tap) mode and effort are invisible until you pull up
D · Pulled-up only nothing; picks appear only in the full-screen composer tray 2 you cannot see what a session runs on without pulling up

My read

B, with the row collapsing to C while a turn is running. The picks belong to the message you are about to send, so they belong on the composer, not the title. At rest you can still read "Opus 5.5 · Agent · High" at a glance, one tap changes any of them, and the header stays a title. While the agent works, the row folds down to the single chip so the transcript gets the space back; it unfolds when you tap the field. Pulling the composer up (D) is the writing mode, not the settings mode — it keeps the same tray so nothing moves.

The context meter moves into the picks row as a tiny bar. The Settings gear on the session's ⋯ menu gets the rarer things: config options, stop background work, title regeneration.
