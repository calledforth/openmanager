New agent palette: polish, switching drafts, switching environments

Mockups only. Carbon theme tokens, real data shape (each draft has a project, provider, first line, image count, edited time and environment). The menus, tabs, rail and toggles all work: click around, and in section 2 try Alt+[ / Alt+] while the card has focus.

01 The card itself: before → after

The divider above the footer goes, the Start button gets slimmer, and it picks up the small Linear touches it's missing: the environment in the breadcrumb, borderless property pills, and a "Start another" switch (Linear's "Create more") that keeps the card open after you start one.

  • No footer divider. The footer sits on the card. Spacing alone separates it from the property pills.
  • Slimmer Start button. It drops from 32px to 26px and says "Start" instead of "Start agent". The ⏎ hint stays. The "Esc save as draft" hint moves into the Close tooltip, which already shows Esc.
  • Borderless pills. The pills lose their outline and get a faint fill, like Linear's current property pills. Effort and permissions get small icons so the row scans quickly.
  • Start another. When it's on, Enter starts the agent and leaves an empty card in the same project, ready for the next one.

02 Switching drafts: a Drafts menu in the header recommended

This is what Linear does: its New issue modal has a Drafts button. Pick a draft and it opens in this same card, in place, without leaving the page you're on. The draft you were writing stays saved, as it already is. Alt+[ / ] steps through drafts without opening the menu.

  • Where the list comes from. It's the same list as the sidebar's draft cards, newest first, so nothing new has to be stored.
  • Breadcrumb follows the draft. Its title becomes the draft's first line, and the project chip changes to the draft's project.
  • Switching away. A draft with text or images stays saved and listed. A blank one is dropped, as it is today.
  • New draft is the first row. ⌘⇧O still opens and closes the card.
  • Other environments. Drafts saved on another machine show under their own heading. Picking one also switches the card's environment (see 05).

03 Alternative: drafts as tabs across the card

Every draft gets a tab along the top, plus a + tab for a new one. You can see them all at a glance, but it gets crowded past about five drafts, and the top of the card looks like a browser.

05 Switching environments from the card

Today the card always uses the environment you're in. This puts the environment first in the breadcrumb, with the same menu as the new-session page. Picking another one moves the card there, and the page you're on stays put. Your text goes with it. Images stay behind, the same as when you switch environments on the new-session page.
